Exam-Style Practice: Recursion & Iteration

1 a Outline the differences between iteration and recursion. [2]

• Iteration uses loops (FOR / WHILE) to repeat instructions. • Recursion uses a function calling itself with a base case.

1 b Give one advantage and one disadvantage of using recursive subroutines. [2]

Advantage: • Recursive solutions can be simpler and easier to understand for some problems. Disadvantage: • Recursion uses more memory because of stack usage.

2 a State what is meant by ‘recursively defined’. [1]

• A function that is defined in terms of a call to itself.

2 b Complete a trace table for the function call Power(2,4). [6]

Call stack trace: Power(2,4) → calls Power(2,3) Power(2,3) → calls Power(2,2) Power(2,2) → calls Power(2,1) Power(2,1) → calls Power(2,0) Power(2,0) returns 1 Power(2,1) returns 2 Power(2,2) returns 4 Power(2,3) returns 8 Power(2,4) returns 16

2 c Explain the role of the stack in the execution of the Power function. [3]

• The stack stores each recursive function call. • It stores parameters and return addresses. • It allows the function to return results in the correct order.

2 d Write a pseudocode non-recursive (iterative) version of the Power function. [6]

FUNCTION Power(Base, Exponent) Result ← 1 FOR Count ← 1 TO Exponent Result ← Result * Base NEXT Count RETURN Result ENDFUNCTION

2 e i Give one reason why a non-recursive Power function may be preferred. [1]

• It uses less memory than a recursive solution.

2 e ii Give one reason why a recursive Power function may be preferred. [1]

• It is easier to understand or matches the mathematical definition.
