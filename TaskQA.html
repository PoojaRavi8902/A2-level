Chapter 23 – Algorithms Tasks

TASK 23.01 – Linear Search

Write program code for the linear search algorithm.


FOR Index ← 0 TO n - 1 IF List[Index] = SearchItem THEN RETURN Index ENDIF NEXT Index RETURN -1

TASK 23.02 – Bubble Sort

Write program code for the most efficient bubble sort algorithm.


Unsorted ← n - 1 FOR i ← 0 TO n - 2 FOR j ← 0 TO Unsorted - 1 IF List[j] > List[j+1] THEN Swap List[j], List[j+1] ENDIF NEXT j Unsorted ← Unsorted - 1 NEXT i

TASK 23.03 – Insertion Sort

1. Dry-run insertion sort for: 53, 21, 60, 18, 42, 19

2. Write program code for insertion sort.


FOR Pointer ← 1 TO n - 1 Item ← List[Pointer] Current ← Pointer - 1 WHILE Current >= 0 AND List[Current] > Item List[Current + 1] ← List[Current] Current ← Current - 1 ENDWHILE List[Current + 1] ← Item NEXT Pointer

TASK 23.04 – Binary Search

Dry-run binary search and compare with linear search.


Binary search halves the data set each iteration (O(log n)). Linear search checks items one by one (O(n)). Binary search is faster for large, sorted lists.
