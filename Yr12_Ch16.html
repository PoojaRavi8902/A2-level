1. Process Scheduling

CPU time • fairness • algorithms
▾

Definition

Process scheduling is the method used by an operating system to decide which process uses the CPU and for how long.

Exam phrase: Scheduling allows multiple processes to share the CPU efficiently.

Why scheduling is required

  • Only one process can use a single CPU core at a time
  • Provides fairness between processes
  • Improves responsiveness in interactive systems
  • Prevents starvation of long or low-priority jobs

Common scheduling algorithms

  • First Come First Served (FCFS): processes run in arrival order
  • Shortest Job First (SJF): shortest CPU burst runs first
  • Round Robin: each process gets a fixed time slice (quantum)
  • Priority scheduling: higher-priority processes run first
Cambridge focus: Round Robin and general idea of fairness & time slicing.

Context switching

When the OS stops one process and starts another, it performs a context switch, saving and restoring registers and program counters.

2. Virtual Memory

Paging • swapping • disk vs RAM
▾

Definition

Virtual memory allows a computer to run programs that require more memory than physically available RAM by using secondary storage.

How it works

  1. Programs are split into fixed-size blocks called pages
  2. Only required pages are loaded into RAM
  3. Unused pages are stored on disk (swap area)
  4. Pages are swapped in and out automatically

Advantages and disadvantages

  • Advantage: programs larger than RAM can run
  • Advantage: better RAM utilisation
  • Disadvantage: disk access is much slower than RAM
  • Disadvantage: excessive paging causes thrashing

3. Compilation Stages

Source code → machine code
▾

What is compilation?

Compilation is the process of translating a high-level language program into machine code that the CPU can execute.

Stages of compilation

1. Lexical analysis – breaks code into tokens 2. Syntax analysis – checks grammar 3. Semantic analysis – checks meaning (types, variables) 4. Code generation – produces machine code 5. Optimization – improves speed/efficiency

Compiler vs Interpreter

  • Compiler translates whole program before execution
  • Errors detected before running
  • Interpreter translates line-by-line at runtime
